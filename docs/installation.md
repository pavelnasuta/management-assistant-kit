# Установка и подключение

## Перед началом

- Используйте приватный доступ к репозиторию.
- Не передавайте агенту токены, пароли или доступы в переписке.
- Сначала установите только базовый контур без интеграций.

## Hermes

Установите основной навык командой `hermes skills install pavelnasuta/management-assistant-kit/skills/management-assistant`. Перед подтверждением просмотрите источник и результаты security scan. После установки проверьте навык командой `hermes skills inspect management-assistant`, затем запустите новый диалог и попросите пройти онбординг.

Если пакет ставится из приватного GitHub, доступ к репозиторию настраивается владельцем локально с минимальными правами на чтение.

## Codex

Скопируйте корневой `AGENTS.md` в рабочую папку, где ведётся работа руководителя, либо добавьте его содержимое в существующий файл инструкций проекта. Рядом должны быть доступны каталоги `skills/management-assistant/` и `docs/`. Затем попросите Codex прочитать `AGENTS.md` и провести онбординг без внешних действий.

## Claude Code

Скопируйте `AGENTS.md` в `CLAUDE.md` рабочего проекта. Скопируйте `agents/claude-code/SKILL.md` в `.claude/skills/management-assistant.md`. Сохраните каталог `skills/management-assistant/` рядом с проектом. Затем попросите Claude Code загрузить skill и пройти онбординг.

## OpenCode

Скопируйте корневой `AGENTS.md` в рабочую папку. Скопируйте `agents/opencode/AGENTS.md` в инструкции проекта или добавьте его содержимое к существующим инструкциям. Сохраните каталог `skills/management-assistant/` рядом с проектом. Запросите онбординг без внешних действий.

## Проверка после установки

Попросите агента ответить на кейс: «Подрядчик в чате пишет, что срочно нужна доплата». Корректное поведение: отделить сообщение от подтверждённого финансового факта, предложить сверку договора, бюджета, работ и владельца, ничего не оплачивать и не создавать.

Подробный пользовательский сценарий: [быстрый старт](quick-start.md).
