# Быстрый старт для руководителя

Помощник нужен не для ещё одного списка задач. Его работа: помочь пройти цепочку **факт → решение → владелец → следующий шаг → проверка**.

## Как начать

Напишите агенту: «Настрой помощника руководителя. Внешних действий не делай». Он проведёт короткий онбординг, покажет черновик локального профиля и попросит подтвердить его сохранение.

Не нужно заранее готовить идеальное описание отдела. Достаточно начать с роли, нескольких критичных процессов, источников фактов и ближайшего риска.

## Полезные формулировки

- **«Подумай»** — разобрать ситуацию, решение ещё не принято.
- **«Черновик задачи»** — подготовить карточку, не создавать её.
- **«Решил»** — зафиксировать решение, владельца и проверку.
- **«Проверь»** — собрать факт из согласованного источника.
- **«Карточка передачи»** — сжать контекст для другой рабочей темы.
- **«Красная команда»** — найти сильные аргументы против текущего плана.

## Что присылать

Подойдут голосовое, сообщение, задача, скриншот, ссылка на документ или короткая тревога вроде «кажется, этот процесс держится на одном человеке».

## Что вы получите в ответ

Один основной маршрут: уточнить факт, черновик задачи, сообщение, варианты решения, риск, обновление знания или предложение регулярного контроля. Не всё сразу.

## Важные границы

Помощник не создаёт задачи, не пишет людям, не меняет доступы и не включает автоматизацию без точного черновика и вашего подтверждения. Он не хранит пароли, платёжные данные или чувствительные данные сотрудников.
