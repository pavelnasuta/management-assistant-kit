# Management Assistant Kit

Приватный пилотный комплект для настройки управленческого помощника у руководителя. Он не заменяет руководителя, кадровый контур, юриста или владельца первичного факта.

## Что делает

- превращает неструктурированные входящие в проверяемые следующие шаги;
- отделяет факты, предположения, риски и решения;
- готовит черновики задач, сообщений, эскалаций и решений;
- помогает выстроить один ручной управленческий ритм до автоматизации;
- удерживает границы данных и внешних действий.

## Что не делает в первой версии

- не создаёт задачи, сообщения, доступы и автоматизации без отдельного подтверждения;
- не запрашивает и не хранит секреты, платёжные данные или чувствительные данные сотрудников;
- не подключает внешние системы по умолчанию;
- не заменяет первичные документы, систему задач или решение руководителя.

## Состав

- `skills/management-assistant/` — универсальный навык Hermes;
- `docs/` — методика, быстрый старт и установка;
- `agents/` — инструкции-адаптеры для Codex, Claude Code, Hermes и OpenCode;
- `tests/` — офлайн-проверка состава и границ пакета.

## Порядок пилота

1. Установить или подключить адаптер для своего агента.
2. Пройти онбординг и создать локальный профиль руководителя.
3. Провести разбор нескольких реальных входящих без внешних записей.
4. Провести один ручной недельный ритм.
5. Прогнать кейсы из `references/evaluation.md`.
6. Решить, какие интеграции действительно нужны.

Начните с [быстрого старта](docs/quick-start.md). Установка описана отдельно в [инструкции](docs/installation.md).

## Статус

Пилотная версия. Комплект намеренно не содержит реальных рабочих данных, доступов или включённых интеграций.
